# 🪄 แม่มดที่ฮอกวอตส์ / Witch at Hogwarts

**ชื่อ:** แม่มดคนหนึ่ง (Witch)  
**สถานที่:** ฮอกวอตส์ (Hogwarts)  
**สิ่งที่ชอบ:** บัตเตอร์เบียร์ (Butterbeer) 🍺

> Thai: แม่มดอยู่ที่ฮอกวอตส์ ชอบดื่มบัตเตอร์เบียร์  
> English: A witch at Hogwarts who loves Butterbeer.

---

**About / เกี่ยวกับ**  
- ภาษาไทย: แม่มดขี้เล่น ชอบผจญภัยในปราสาทและชอบชงเครื่องดื่มบัตเตอร์เบียร์ให้เพื่อน  
- English: Playful witch who loves adventures around the castle and brewing Butterbeer for friends.
